# AI-Content-Funnel

## Описание
AI-Content-Funnel — это инструмент для автоматизированной обработки, проверки и управления видеоконтентом (воронка контента). 

## Основной функционал
- **Обработка видео:** скрипты для проверки и валидации видео (`check_video.ts`, `check_video2.ts` и др.).
- **Управление очередями:** автоматизация процессов через `check_queue.ts`.
- **Интеграция с YouTube:** патчи и скрипты для работы с платформой (`patch_youtube.py`).
- **Связь с Firebase:** готовая конфигурация `firebase-applet-config.json` для хранения данных или авторизации.

## Стек технологий
- **Frontend / Backend:** TypeScript, Vite, Node.js (или Bun)
- **Скрипты:** Python
- **База данных / Инфраструктура:** Firebase
